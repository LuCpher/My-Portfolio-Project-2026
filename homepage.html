Learning Reflection
What have I learned?

Throughout this course, I gained a better understanding of how websites are designed, developed, and maintained using fundamental web technologies. Before taking the course, I already had some basic knowledge of programming, but this subject allowed me to apply those concepts in a more practical way through the creation of web pages and projects. I learned how HTML provides the structure of a webpage, CSS controls its appearance and layout, and JavaScript adds interactivity and functionality to improve the user experience.


During development, I encountered several challenges. Some of the difficulties included figuring out what and how should I make the page and the design while also learning the technical aspects of web development. I also had to troubleshoot various issues such as, troubleshooting broken links, managing project files, and understanding how different CSS properties interact with one another. There were also moments when JavaScript functions did not behave as expected, requiring additional testing and debugging to identify the source of the problem.


To overcome these challenges, I relied on online resources like youtube tutorials, some help from other programmers, and continuous experimentation with a bit of AI help. Instead of immediately rewriting large portions of code, I learned to firstly figure out what the content of my website should be then how it should look like, then I would design the website as I envision it and that is when I create the mind of my website then that's when I have to debug systematically by checking file paths, check syntax error, and test different solutions and individual elements one step at a time. This approach helped me solve problems more efficiently while improving my understanding of how websites function behind the scenes.


With that, this course helped me develop both technical and personal skills. Aside from gaining knowledge in web development, I improved my patience, problem-solving abilities, and willingness to learn independently. The experience taught me that mistakes are a normal part of the development process and that every challenge presents an opportunity to learn something new. As I continue my journey as an Information Technology student, I hope to further develop these skills and apply them to future academic projects and professional opportunities.
